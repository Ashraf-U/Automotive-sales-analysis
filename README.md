# Automotive Sales & Customer Analysis

## Project Overview

This project analyzes automotive sales data using MySQL.

The analysis focuses on customers, vehicles, dealers, orders, revenue, pricing, and sales performance.

The goal is to answer common business questions that could be relevant to an automotive company's sales and customer analytics teams.

## Tools & Technologies

- MySQL
- MySQL Workbench
- SQL

## Database Structure

The project contains four main tables:

### Customers
Contains customer demographic and location information.

### Dealers
Contains dealer information including location and dealer type.

### Vehicles
Contains vehicle information including brand, model, vehicle type, fuel type, production year, and list price.

### Orders
Contains sales transaction information including customer, dealer, vehicle, order date, selling price, discount, quantity, payment method, and order status.

## Business Questions

The project answers 30 business questions, including:

1. Which customers are from Frankfurt?
2. Which vehicles have a list price above €50,000?
3. Which orders used financing?
4. Which vehicles are SUVs with Diesel engines?
5. How many customers are in the database?
6. What is the average customer age?
7. What are the minimum, maximum, and average vehicle prices?
8. How many customers are in each state?
9. How many vehicles does each brand have?
10. What is the average vehicle price by brand?
11. How many orders does each dealer have?
12. What is the total revenue by brand?
13. What is the most frequently used payment method?
14. What is the average discount by brand?
15. Which customers purchased which vehicles?
16. Which dealers have the most orders?
17. What is the revenue generated by each dealer?
18. Who are the top 5 customers by spending?
19. Which vehicle model is the most frequently ordered?
20. How can customers be categorized by age?
21. How can vehicles be categorized by price?
22. Which customers are older than the average customer?
23. Which vehicles are more expensive than the average vehicle?
24. Which customers spend more than the average customer?
25. How do vehicle models rank by total revenue?
26. How do vehicles rank by price within each brand?
27. Which model generates the highest revenue within each brand?
28. How does each order compare with the average selling price?
29. How do dealers perform based on orders and revenue?
30. Which vehicle models perform best within each brand?

## Key Analysis Areas

### Customer Analysis

Analyzed customer demographics, locations, age groups, and spending behavior.

### Vehicle Analysis

Analyzed vehicle brands, models, pricing, fuel types, and vehicle categories.

### Sales Analysis

Analyzed order volume, revenue, payment methods, discounts, and customer spending.

### Dealer Analysis

Compared dealer order volume and revenue performance.

### Ranking Analysis

Used SQL window functions to rank vehicles and models within brands.

6. Run `04_analysis.sql`.
7. Review the query results in MySQL Workbench.
